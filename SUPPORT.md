# Support

## Merchants and buyers

Email **hello@punchrelay.com**. Include your store domain and, for connection problems, the procurement system involved (Ariba, Coupa, Jaggaer, OCI and so on) and a timestamp of the failed request.

Documentation and setup guides are at [punchrelay.com](https://punchrelay.com).

## Security issues

See [SECURITY.md](SECURITY.md). Do not report security issues in public.

## Issues in this organization's repositories

Open an issue in the relevant repository. Give the steps to reproduce, the expected result and the actual result.
